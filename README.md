### The Game

Simple to play — hard to outlast — endlessly replayable.

The countryside has been overrun by feral weasels and other monsters. 

You start small and wird a fairy and a sword, dodging the first wave with nothing but grit. But as you collect glowing orbs and relics, you gain new abilities — turning into a walking storm of blades, blasts, and traps. How long can you last before the swarm overwhelms you?

This is a quick-session, roguelite survival game built with Godot. Every run is a fresh challenge, with random power-ups and scaling enemy waves.
